One time setup

This board is a single file with no server, so it talks to Google straight from your browser. That needs a free Google client ID tied to your own account. You do this once.

  1. Open console.cloud.google.com and make a new project (any name).
  2. In APIs and Services, enable the Google Calendar API.
  3. Open OAuth consent screen, choose External, fill the basics, and add your own Gmail address under Test users.
  4. Open Credentials, create an OAuth client ID of type Web application.
  5. Under Authorised JavaScript origins add your live site address, for example https://pratimnarayan.com and your Netlify address. The address must be https, not a file opened from your phone.
  6. Copy the Client ID and paste it below.

Your client ID stays in this browser only. It is not a password and is safe to keep in the page.
